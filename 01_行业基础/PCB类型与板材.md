# PCB 类型与板材

> 摘要：PCB 按结构分为刚性板、柔性板（FPC）、刚挠结合板；按密度工艺分为普通板与 HDI 板；按应用分为高频高速板等。板材选择由频率、层数、可靠性要求共同决定，核心是基材的 Tg、Td、Dk、Df、CTE 五项参数。

## 一、按结构分类

### 1. 刚性板（Rigid PCB）
- 最常见的 PCB，基材不可弯折，占市场主体。
- 常见基材：FR-4（玻纤布 + 环氧树脂），通用、性价比高；按 Tg（玻璃化转变温度）分为普通 Tg（约130-140℃）、中 Tg（约150℃）、高 Tg（≥170℃）。高 Tg 板耐热性好，适合多层板、汽车电子和高温环境。
- 单面板 / 双面板：1-2 层，仅一面或两面布线，工艺成熟、成本最低，用于家电、电源、简单控制板。
- 多层板：4 层及以上，通过层压把多层线路叠合，配合通孔/盲埋孔实现层间互连，是通信设备、工控、汽车电子的主力。
- 刚性板是 PCB 的主体品类，全球约九成电子设备依靠刚性板完成信号传输与电源分配。

### 2. 柔性板（FPC，Flexible Printed Circuit）
- 基材为 PI（聚酰亚胺）或 PET，可弯折、可动态弯折（如翻盖、滑动结构）。
- 优点：轻薄、三维布线、抗振动；缺点：成本高于刚性板，组装需专用治具。
- 按层数分为单面 FPC、双面 FPC、多层 FPC；按使用方式分为静态弯折与动态弯折，动态弯折对铜箔延展性、覆盖膜与弯折半径要求更高。
- 常见应用：手机排线、摄像头模组、可穿戴设备、动力电池采样线束（FPC 替代传统线束）。

### 3. 刚挠结合板（Rigid-Flex PCB）
- 刚性区域与柔性区域压合为一体，实现三维互连，替代连接器+线缆方案。
- 价值：减少连接点（提高可靠性）、缩小空间、减轻重量。主要用于医疗设备、航空航天、高端手机、摄像头模组。
- 工艺难点：异质材料（FR-4 + PI）压合对位、挠性区开窗、多次压合，良率控制难，价格显著高于普通板。

## 二、按工艺密度分类

### HDI 板（High Density Interconnect，高密度互连板）
- 特征：盲孔/埋孔、微孔（激光孔，孔径通常 ≤0.15mm）、细线宽线距（≤3/3mil 常见）。
- 典型结构：1+N+1、2+N+2（N 为普通芯板层数，数字为 HDI 积层次数）。
- 应用：智能手机、可穿戴、高端服务器。AI 服务器带动高阶 HDI（mSAP 细线路工艺）需求增长。

### 普通多层板
- 4-40+ 层，机械钻孔、通孔为主，是通信设备、工控、汽车电子的主力。

### IC 载板（封装基板）
- 芯片封装与 PCB 之间的桥梁，线宽线距最小（可至 10μm 级），技术门槛最高的细分品类。
- 主要类型：BT 载板（存储、射频、MEMS）、ABF/FC-BGA 载板（CPU/GPU 等大芯片）、FC-CSP 载板（移动终端）。

### 类载板（SLP，Substrate-Like PCB）
- 用 PCB 工艺逼近载板精度的产品，线宽线距约 20-40μm，介于高阶 HDI 与 IC 载板之间，用于高端手机主板与可穿戴。

## 三、按电性能分类：高频高速板

- **高频（RF）板**：处理射频信号，关键指标为介电常数 Dk（低且稳定）和损耗因子 Df（低损耗）。常见材料：Rogers（罗杰斯，如 RO4350B）、Taconic、PTFE 基材，或与 FR-4 混压。
- **高速数字板**：服务器、交换机用，关注低损耗层压材料（如 Mid/Low Loss、Ultra Low Loss 级别）、阻抗控制精度。
- 应用：5G 天线/基站、卫星、雷达、AI 服务器与高速交换机（224G 时代对材料要求进一步提升）。

## 四、选材逻辑速查

| 需求场景 | 推荐方向 |
|----------|----------|
| 通用消费电子、打样 | FR-4（普通/中Tg） |
| 多层板、汽车电子、高温环境 | 高 Tg FR-4 |
| 需要弯折/三维装配 | FPC（PI 基材） |
| 高可靠 + 空间紧凑 | 刚挠结合板 |
| 手机/可穿戴高密度布线 | HDI（1+N+1 起步） |
| 射频/毫米波、AI服务器高速链路 | Rogers/低损耗材料，必要时混压 |
| LED 照明、大功率电源 | 金属基板（铝基/铜基） |
| 高功率模块、IGBT | 陶瓷基板（Al2O3 / AlN） |

## 五、基材关键参数与选型指标

选材不能只看"是不是 FR-4"，要落到六个可量化指标：

- **Tg（玻璃化转变温度）**：树脂由玻璃态转为高弹态的温度，决定回流焊与高温服役下的尺寸稳定性。普通 Tg 约 130-140℃，中 Tg 约 150℃，高 Tg 通常 ≥170℃；无铅回流焊与车规场景建议选 Tg ≥170℃。
- **Td（热分解温度）**：树脂开始热失重的温度，高 Tg 板普遍要求 Td ≥340℃，是判断无铅工艺耐热上限的硬指标。
- **Dk（介电常数）**：影响信号传播速度与阻抗，数值越低、随频率越稳定越好。
- **Df（损耗因子）**：决定高频信号衰减，是高速材料分级（Mid Loss / Low Loss / Ultra Low Loss）的核心参数。
- **CTE（热膨胀系数）**：Z 轴 CTE 影响孔壁铜在热冲击下是否断裂，高多层板与厚铜板尤其敏感。
- **CTI（相比漏电起痕指数）**：影响爬电距离设计，电源、高压、工业类产品需要高 CTI 板材。

### 常见基材典型参数对比（10GHz 附近典型值，具体以材料厂商 datasheet 为准）

| 基材类型 | 代表材料 | Dk | Df | 典型用途 |
|---------|---------|----|----|---------|
| 普通 FR-4 | Tg 140℃ 级 | 4.3-4.6 | 0.018-0.022 | 消费电子、普通工控 |
| 高 Tg FR-4 | Tg 170℃ 级 | 4.2-4.4 | 0.015-0.020 | 多层板、汽车电子 |
| 中损耗（Mid Loss） | 松下 M4 级 | 3.9-4.1 | 0.008-0.010 | 服务器、交换机 |
| 低损耗（Low Loss） | 松下 M6 级 | 3.6-3.8 | 0.004-0.006 | 高速背板、光模块 |
| 超低损耗 | 松下 M7/M8 级 | 3.2-3.5 | 0.0015-0.003 | 224G 高速链路、AI 服务器 |
| 高频碳氢 | Rogers RO4350B | 3.48 | 0.0037 | 5G 天线、毫米波 |
| 高频 PTFE | Rogers RO3003 | 3.00 | 0.0010 | 射频前端、雷达 |

> 说明：Dk/Df 随频率变化，表中为 10GHz 附近典型值；同一等级不同厂牌数值有差异，选型应以具体型号 datasheet 与叠层仿真为准。

### 金属基板与陶瓷基板

- **金属基板（MCPCB）**：以铝或铜为底层，中间为绝缘导热层，导热能力远高于 FR-4，用于 LED 照明、电源模块、汽车大灯等大功率散热场景。
- **陶瓷基板（Al2O3、AlN）**：导热与耐高温性能最好，用于 IGBT、功率模块、高频高功率器件；成本最高、可加工尺寸受限。

## 六、高频高速材料选型逻辑

1. **先定频率与速率**：低于 1GHz 的普通数字电路，高 Tg FR-4 即可；1-10GHz 的射频与 10Gbps 以上链路进入 Mid/Low Loss 区间；224G SerDes 与毫米波需要 Ultra Low Loss 或 PTFE。
2. **再算损耗预算**：链路总损耗 = 介质损耗 + 导体损耗 + 过孔与连接器损耗。频率越高，介质损耗占比越大，升级材料的收益越明显。
3. **成本折中靠混压**：只在关键层使用高频材料、其余层用 FR-4，通过混压（Hybrid Lamination）控制成本，但需解决不同材料 CTE 与流胶匹配问题。
4. **阻抗与叠层协同设计**：Dk 决定线宽，换料会改变目标阻抗线宽，必须与叠层（Stack-up）联合仿真，避免"换了材料要改设计"。

## 七、层叠（Stack-up）设计要点

- **对称性**：层压结构上下应对称（介质厚度、铜厚、层数），不对称会导致板翘曲。
- **参考层完整**：高速信号层应有完整的地/电源参考平面，避免跨分割造成阻抗突变与 EMI。
- **阻抗控制**：常见目标为单端 50Ω、差分 90Ω/100Ω；量产阻抗公差常规 ±10%，高速板要求 ±7% 甚至 ±5%。
- **铜厚与电流**：外层常规 1oz（约 35μm），大电流用 2oz 及以上；电源层铜厚按温升与载流计算确定。
- **盲埋孔规划**：HDI 结构决定积层次数与激光孔位置，需在设计阶段与板厂 DFM 确认可制造性。

## 八、表面处理工艺对比

| 工艺 | 厚度参考 | 平整度 | 成本 | 适用场景 |
|------|---------|-------|------|---------|
| HASL（喷锡，有铅/无铅） | 1-25μm | 一般 | 最低 | 大焊盘、平整度要求低的板 |
| OSP（有机保焊膜） | 0.2-0.5μm | 好 | 低 | 无铅环保、周转快的消费板 |
| ENIG（化学镍金） | 镍 3-6μm + 金 0.05-0.1μm | 最好 | 中高 | 细间距、BGA、需长期储存 |
| 沉银 / 沉锡 | 0.1-1μm | 好 | 中 | 替代 ENIG 的平整处理 |
| 电镀镍金（硬金） | 镍 2-5μm + 金 0.5-3μm | 好 | 高 | 金手指、按键、耐磨接口 |

- 选择原则：有 BGA/细间距 → ENIG 或沉银；金手指/耐磨 → 电镀硬金；成本优先且周转快 → OSP 或喷锡。
- ENIG 的"黑盘"（镍层腐蚀导致可焊性下降）与沉银的"银迁移"是常见失效风险，需在来料与储存条件上管控。

## 九、无卤素与环保基材

- **无卤素（Halogen-Free）板材**：溴、氯等卤素含量低于限值（溴 ≤900ppm、氯 ≤900ppm、卤素总量 ≤1500ppm，依据 IEC 61249-2-21），燃烧时发烟与腐蚀性气体更少。出口欧盟与部分大客户对卤素有限制，下单前需确认。
- **高 CTI 板材**：CTI（相比漏电起痕指数）越高，允许的爬电距离越小，适合高压、电源与工业产品；通常 CTI ≥600V 可视为高 CTI 级别。
- **无铅兼容板材**：需耐受无铅回流焊峰值温度（约 260℃），一般要求 Tg ≥170℃、Td ≥340℃。

## 十、按应用分类速查

| 应用 | 典型板类型 | 关键要求 |
|------|-----------|---------|
| 消费电子 | 单/双面、4-8 层、HDI | 成本、轻薄 |
| 通信设备 | 高多层、高频 | 阻抗控制、低损耗 |
| 汽车电子 | 高 Tg 多层、厚铜、金属基板 | 高可靠、宽温、IATF16949 |

| AI 服务器 | 高多层、高阶 HDI | 超低损耗、高层数、大尺寸 |
