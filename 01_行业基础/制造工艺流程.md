# PCB 制造工艺流程

> 摘要：PCB 制造核心流程为：开料 → 内层图形 → 层压 → 钻孔 → 沉铜电镀 → 外层图形 → 蚀刻 → 阻焊 → 表面处理 → 成型 → 电测 → 终检。HDI 增加激光钻孔与积层压合，刚挠结合需异质材料压合，厚铜/金属基板/高频混压各有专属难点。

## 一、刚性板标准流程（减成法为主线）

1. **开料（Cutting）**：将大张覆铜板裁切成生产尺寸。
2. **内层图形转移**：贴干膜 → 曝光 → 显影，把内层线路图形转移到铜面。
3. **内层蚀刻**：蚀掉无干膜保护的铜，形成内层线路，退膜后 AOI（自动光学检测）检查。
4. **层压（Lamination）**：内层板 + 半固化片（PP）+ 铜箔在高温高压下压合成整体。多层板需棕化/黑化处理增加结合力。
5. **钻孔（Drilling）**：机械钻孔形成层间导通孔（通孔）。孔径越小、板越厚，难度越高（纵横比限制）。
6. **沉铜（PTH，化学镀铜）+ 电镀（Plating）**：孔壁原本是绝缘树脂，需先化学沉铜金属化，再电镀加厚，实现层间导通。
7. **外层图形 + 图形电镀 + 蚀刻**：同内层逻辑，铜层线路在外层成型。
8. **阻焊（Solder Mask）**：印刷绿油（或其他颜色），保护线路、定义焊接开窗；字符印刷（丝印）标注位号。
9. **表面处理（Surface Finish）**：保护焊盘可焊性。常见工艺：
   - HASL（喷锡，有铅/无铅）：成本低，适合大焊盘
   - ENIG（化学镍金）：平整、可焊性与储存性好，主流选择
   - OSP（有机保焊膜）：成本低、无铅环保，但保存期短
   - 沉银 / 沉锡 / 电镀镍金（硬金，用于金手指、按键）
10. **成型（Routing/冲压）**：铣边成型，V-Cut 或邮票孔连接拼版。
11. **电测（E-Test）**：飞针测试（小批量）或测试架（量产），验证开短路。
12. **FQC/FVI 终检**：外观、尺寸、阻抗报告，出货。

> 说明：以上为减成法（Subtractive）流程；HDI 与类载板会引入半加成（SAP/mSAP）工序，见下节。

## 二、HDI 附加工艺

- **激光钻孔（Laser Via）**：CO2/UV 激光打微孔，孔径 ≤0.15mm，代替机械钻孔做层间积层互连。
- **积层法（Build-up）**：芯板 → 压积层材料 → 激光孔 → 电镀填孔 → 再压下一层，循环完成 1+N+1 / 2+N+2 结构。
- **电镀填孔（Via Filling）**：盲孔内填实铜，为堆叠孔（Stack Via）打基础。
- **mSAP（改良半加成法）**：高阶 HDI 用于实现 ≤30μm 细线路。
- **SAP（半加成法）**：比 mSAP 更精细，用于类载板与 IC 载板的极细线路。

## 三、刚挠结合板工艺要点

- 异质材料（FR-4 + PI）压合：两种材料膨胀系数不同，对位与结合力控制是核心难点。
- 挠性区需开窗、补强（Stiffener）设计；层压后弯曲区域不能有胶溢出、铜箔开裂。
- 通常需要多次压合，周期长、良率敏感，报价显著高于普通板。

## 五、各工序良率影响因素

- **开料**：板材批次一致性、烘板去应力是否执行，影响后续尺寸稳定性与翘曲。
- **内层图形与蚀刻**：曝光能量、显影/蚀刻液浓度、蚀刻均匀性决定线宽公差；细线路对洁净度与设备精度要求最高。
- **层压**：升温速率、压力曲线、流胶量、对位精度决定层间结合力与层偏；厚板与高层数板需分段压合。
- **钻孔**：钻头磨损、转速与进给、盖/垫板、排屑决定孔壁质量与孔位精度；纵横比越大，孔壁铜越难均匀。
- **沉铜电镀**：孔壁活化与化学铜覆盖、电镀电流分布（深镀能力）决定孔铜厚度均匀性；孔铜不足会引发热冲击断裂。
- **阻焊与字符**：前处理清洁度、网版/曝光对位、固化曲线决定阻焊附着力与开窗精度。
- **表面处理**：药液浓度与时间、后清洗决定镀层厚度与可焊性；ENIG 需防"黑盘"。
- **成型与电测**：铣刀/模具精度决定外形公差；测试覆盖率与探针接触决定开短路拦截率。

## 六、特殊工艺与难点

### 1. 厚铜板（Heavy Copper）
- 定义：外层或内层铜厚 ≥2oz（约 70μm），常见 3-6oz，用于大电流、高散热场景（电源、汽车电控、工业变频）。
- 难点：厚铜蚀刻难（侧蚀大、线宽公差难控）、层压填胶难（需高流胶 PP 或多次压合）、钻孔与电镀难度上升。

### 2. 金属基板（铝基/铜基，MCPCB）
- 结构：金属底层 + 绝缘导热层 + 铜箔线路。
- 难点：绝缘层耐压与导热性能的平衡、金属与树脂热膨胀失配导致翘曲、机械加工（冲压/铣切）毛刺控制。

### 3. 高频混压板
- 难点：PTFE/碳氢材料与 FR-4 的流胶、CTE、压合温度曲线差异大，易分层；PTFE 孔壁处理与电镀附着性差，需特殊前处理。
- 价值：只在关键层使用高频材料，可在满足射频性能的同时控制成本。

### 4. 埋入式元件与铜块嵌入
- 埋入电阻/电容可提高集成度、改善高频性能；铜块嵌入（Coin Insertion）用于大电流散热。
- 难点：埋入件与树脂的界面结合、压合平整度、后续工序耐受性。

## 七、检测与质量控制环节

- **AOI（自动光学检测）**：内层/外层线路图形检测，拦截开路、短路、缺口、针孔。
- **电测（E-Test）**：飞针（小批量、灵活）或专用测试架（量产、效率高），实现开短路测试。
- **切片分析**：显微观察孔铜厚度、层间对位、树脂塞孔、镀层结构，是可靠性验证的核心手段。
- **阻抗测试（TDR）**：按叠层设计要求实测差分/单端阻抗，出具阻抗报告。
- **热应力与可焊性测试**：按 IPC-TM-650 方法执行，验证孔壁与镀层耐热可靠性。
- **离子污染度测试**：控制残留离子，避免电化学迁移与漏电。
- **最终质量门禁**：外观（IPC-A-600）、尺寸、电性能、可靠性抽检、出货报告（COC）齐套后方可出货。

## 八、常见工艺缺陷与成因

| 缺陷 | 常见成因 | 影响 |
|------|---------|------|
| 板翘曲 | 叠层不对称、压合应力、开料未烘板 | 影响 SMT 贴装、二次加工 |
| 层偏 | 层压对位偏差、材料涨缩 | 阻抗异常、孔环不足 |
| 孔壁铜薄/断裂 | 钻孔质量差、深镀能力不足 | 热冲击后开路，可靠性隐患 |
| 蚀刻不净/侧蚀 | 蚀刻参数失控、线宽过细 | 开路/短路、阻抗偏差 |
| 阻焊气泡/脱落 | 前处理不洁、固化不足 | 焊接不良、外观判退 |
| 镀层黑盘（ENIG） | 镍层氧化腐蚀 | 可焊性下降、焊点脆裂 |
