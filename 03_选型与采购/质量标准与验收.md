# 质量标准与验收

> 摘要：PCB 行业验收以 IPC 标准为核心：IPC-A-600（成品板外观验收）、IPC-A-610（组装验收）、IPC-6012（成品板性能规范），Class 1/2/3 三个等级对应消费、工业、高可靠场景。采购必须写明标准版本与验收等级。

## 一、IPC 核心标准体系

| 标准 | 内容 | 适用 |
|------|------|------|
| IPC-A-600 | 印制板外观验收（目检判据：镀层、阻焊、标记、外伤等） | 裸板出厂验收 |
| IPC-6012 | 刚性印制板性能与 qualification 规范 | 裸板性能要求 |
| IPC-A-610 | 电子组装件外观验收 | PCBA 组装验收 |
| IPC-2221 | 设计通用标准 | 设计端 |
| IPC-4101 | 覆铜板基材规范 | 材料端 |
| IPC-TM-650 | 测试方法汇编（切片、热应力等） | 检验方法 |

## 二、三个验收等级（Class）

- **Class 1（普通消费类）**：允许的功能件，外观要求最低，成本导向。
- **Class 2（专用服务类）**：绝大多数工业、通信、消费电子采用；要求持续功能、高外观标准。
- **Class 3（高可靠类）**：航空航天、医疗、汽车、军工；要求持续高性能，不允许苛刻环境失效。采购时必须明确写明等级。

## 三、出厂验收要点清单

1. **外观**：阻焊有无起泡/偏位、线路有无缺口/针孔、板边有无毛刺（对照 IPC-A-600）。
2. **尺寸**：板厚、外形公差、孔径（用通止规/二次元）。
3. **电性能**：开短路测试（100% 电测）、阻抗报告（有阻抗要求的订单）。
4. **可靠性抽检**：切片分析（镀铜厚度、孔铜、层间对位）、热应力测试、可焊性测试。
5. **文件**：出货报告（COC）、 impedance report、切片报告（按约定）。

## 四、行业附加认证

| 行业 | 典型要求 |
|------|----------|
| 汽车 | IATF16949 体系、车规材料（高 Tg、CTE 匹配）、温度循环/AEC-Q 相关可靠性 |
| 医疗 | ISO13485 体系；植入/接触类有生物兼容性要求 |
| 军工/航天 | 国军标/AS9100，Class 3 验收，全程可追溯 |
| 出口欧盟 | RoHS / REACH 有害物质合规 |

## 五、标准体系的层级关系（设计—材料—制造—验收）

- **设计端**：IPC-2221（刚性板设计通用标准）、IPC-2223（挠性板设计）、IPC-7351（焊盘图形）。
- **材料端**：IPC-4101（刚性覆铜板规范）、IPC-4202 / 4203（挠性覆铜板）。
- **制造端**：IPC-6012（刚性板性能）、IPC-6013（挠性板性能）、IPC-6015（封装基板）、IPC-6018（高频板）。
- **验收端**：IPC-A-600（裸板外观）、IPC-A-610（组装件外观）、J-STD-001（焊接要求）。
- **测试方法**：IPC-TM-650 系列（切片、热应力、可焊性、离子污染度等）。
- **采购提示**：合同应同时锁定"标准编号 + 版本年份 + Class 等级"，避免不同版本判据差异引起争议。

## 六、Class 1/2/3 判定细节对比

| 维度 | Class 1 | Class 2 | Class 3 |
|------|---------|---------|---------|
| 适用 | 普通消费类 | 专用服务类（工业/通信/消费电子） | 高可靠（航空/医疗/汽车/军工） |
| 孔铜厚度 | 允许较薄 | 一般要求 ≥20μm | 要求 ≥25μm 且均匀性更严 |
| 外观缺陷 | 允许不影响功能的外观缺陷 | 外观与功能均需高一致性 | 不允许影响可靠性的任何缺陷 |
| 返修 | 相对宽松 | 受控返修 | 严格受控，返修需记录与批准 |
| 检验强度 | 抽检为主 | 抽检 + 关键项 100% | 100% 关键项 + 可追溯 |
| 成本 | 最低 | 中 | 最高 |

> 注：孔铜厚度等具体数值以 IPC-6012 对应版本条款为准，表中为行业常见要求示意；采购时应写明标准版本与 Class 等级，并以订单技术协议为准。

## 七、出厂验收测试项与判定标准

| 测试项 | 方法 / 依据 | 判定要点 |
|--------|------------|---------|
| 外观 | IPC-A-600 | 阻焊、字符、镀层、外伤、板边毛刺 |
| 尺寸 | 二次元 / 通止规 | 板厚、外形、孔径、孔位符合图纸 |
| 开短路 | 电测（飞针 / 测试架） | 100% 测试，无开短路 |
| 阻抗 | TDR（IPC-TM-650） | 符合叠层设计目标，公差按订单约定 |
| 孔铜 / 镀层 | 切片（IPC-TM-650 2.1.1） | 孔铜厚度、层间对位、镀层结构 |
| 热应力 | IPC-TM-650 2.6.8 | 浮锡后无分层、无孔壁断裂 |
| 可焊性 | IPC-TM-650 可焊性方法 | 润湿良好、无退润湿 |
| 离子污染 | IPC-TM-650 2.3.25 | 残留离子低于约定值 |
| 包装 / 标识 | 目检 + 真空包装 | 无污染、防潮、批次标识齐全 |

- **抽检比例**：常规订单按 AQL 抽检，车规/医疗订单关键项 100% 检验，具体要求写入质量协议。
- **留样**：建议保留出货样品与检测数据，便于后续客诉追溯。

## 八、常见外观缺陷判据（IPC-A-600 要点）

- **阻焊**：起泡、脱落、偏位、上焊盘（阻焊上焊盘）按 Class 判定，Class 3 通常不容许。
- **线路**：缺口、针孔、铜刺、残铜；线路宽度减少量超过允许值即判退。
- **孔**：孔环不足、破环、塞孔不良、孔壁空洞。
- **镀层**：ENIG 黑盘、镍腐蚀、镀层空洞、镀层结合力不足。
- **标记**：字符模糊、错印、缺失。
- **板边与外形**：毛刺、分层、白斑（measling）、爆板。
- **判据原则**：Class 3 对"影响可靠性"的缺陷零容忍；Class 2 允许有限度的外观偏差；Class 1 以功能可用为准。

## 十、验收文件与索赔流程

- **随货文件**：出货报告（COC / COA）、尺寸报告、阻抗报告、切片报告、RoHS 报告（按需）。
- **验收流程**：来料外观 → 尺寸抽检 → 电测复核 → 可靠性抽检（切片/热应力）→ 判定合格 / 让步接收 / 判退。
- **不合格处理**：8D 报告、返工 / 重做 / 赔付、原因分析（来料 / 设计 / 制程）与纠正措施。
- **索赔要点**：保留不良样本与照片、在约定时效内（常见 30 天内）提出、按合同约定的赔付比例执行，避免超过时效丧失索赔权。
- **责任界定**：PCBA 阶段才发现的问题可能涉及设计与组装，需保留原始检测数据以便界定责任。

## 十一、常见验收争议与处理

- **"外观不良"是否判退**：以 IPC-A-600 对应 Class 条款为准，标注判据条款并附照片，避免主观争议。
- **孔铜厚度争议**：以切片实测数据为准，事先约定测量位置与取样数量（每批几块板、每板几个孔）。
- **阻抗超差责任**：先核对是否按确认叠层生产；叠层与线宽无误则偏制程，设计未提供叠层则责任在设计端。
- **翘曲超差**：明确测量方法与基准（回流焊前后、是否压在平台上测量），并约定允许值。
- **交期延误**：按合同约定的起算点与赔付条款处理；因客户变更资料或延迟确认 EQ 导致的顺延不属违约。
- **处理原则**：一切以书面技术协议与检测数据为准，先界定责任再谈赔付，避免口头承诺。
