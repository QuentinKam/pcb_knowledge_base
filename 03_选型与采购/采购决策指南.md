# 采购决策指南

> 摘要：PCB 供应商评估用五维法（交期、价格、品质、服务、口碑）；报价受层数、板材、工艺、数量、交期多重影响；只比单价是采购最大误区，正确的比较口径是"总拥有成本（TCO）"。

## 一、厂商评估五维法

1. **交期**：打样常见 3-7 天（快板可 24-48 小时加急），量产 2-4 周。确认加急能力与准时率。
2. **价格**：同一工艺参数下多家比价；警惕显著低于市场价的报价（见"避坑"）。
3. **品质**：最难直观判断，重点看设备与检测能力——是否具备 AOI、飞针/测试架、阻抗测试、切片分析；是否有 ISO9001、IATF16949（车规）、ISO13485（医疗）等体系认证。
4. **服务**：工程答疑（EQ）响应速度、DFM 可制造性分析是否免费、问题板返工/赔付政策。
5. **口碑**：同行推荐、公开评价、成立年限与客户结构。

## 二、影响报价的关键变量

- **层数**：最直接的涨价因子，层数越高工艺越复杂。
- **板材**：FR-4 普通 Tg < 高 Tg < 高速材料（如 M6 级）< Rogers 高频板。
- **最小线宽线距 / 最小孔径**：越细越小，越贵（超出常规产能需特殊工艺）。
- **表面处理**：OSP < 喷锡 < ENIG < 电金。
- **数量与拼版方式**：拼版利用率直接影响单价；V 割、邮票孔、阴阳拼版选择影响后续 SMT 成本。
- **交期**：加急通常上浮 30%-100%。

## 三、常见避坑清单

1. **只比单价不看基材等级**：低价可能用降级基材——样机阶段正常，批量长期使用后可靠性出问题。
2. **忽略行业认证**：车载板须满足温度循环等车规要求；医疗板有生物兼容性等附加测试；只对比基础参数会选错供应商。
3. **快板选停产/小众料件**：快板追求快速交付，应选现货充足的通用元器件（PCBA 场景）。
4. **不提供或无视 DFM 反馈**：焊盘设计不合理、器件到板边距离不足、BOM 与焊盘不符等缺陷应在投产前通过 DFM 评审拦截。
5. **合同未约定验收标准**：应在订单中明确按 IPC-A-600（成品板）Class 2/3 等验收等级。
6. **忽略一次性费用**：只比板费，忘了 NRE 工程费、测试架费、运费与关税，最终总价反而更高。
7. **口头承诺不留痕**：工艺能力、交期、赔付必须落进合同或正式邮件，避免"销售说的"无法兑现。
8. **不验证产能真实性**：小厂报价低但交期不稳，旺季被大客户挤产，需核实设备与月产能。

## 四、打样 vs 量产决策

| 阶段 | 重点 | 建议 |
|------|------|------|
| 研发打样 | 快、可改 | 选快板厂，交期优先，数量 5-10 片 |
| 小批量试产 | 工艺一致性 | 用打样同厂或同工艺验证，50-500 片 |
| 量产 | 成本 + 稳定性 + 产能 | 正式供应商审核（审厂）、签质量协议、明确 IPC 等级 |

- 换厂原则：从打样转向量产时，尽量选择同一家或同工艺能力的工厂，避免"打样能过、量产做不出"。
- 若必须换厂，应要求新厂先做小批量验证并出具切片与阻抗报告，再放量。

## 五、报价成本结构拆解（一块板的钱花在哪）

PCB 报价的构成大致可分为以下部分（比例随层数、工艺、批量变化）：

- **基材（覆铜板 / 半固化片）**：普通 FR-4 占比约 20-35%，高频高速材料可占 50% 以上，是成本第一变量。
- **工程费（NRE / 工程资料）**：含 CAM 制作、MI 审核、光绘与模板，打样阶段按款一次性收取，批量可摊薄或免收。
- **钻孔与成型**：机械钻孔 / 激光钻孔工时、铣边或模具费。
- **图形与蚀刻**：干膜、曝光、显影、蚀刻、AOI，与线宽精度和层数强相关。
- **表面处理**：OSP 最低，ENIG / 沉银居中，电镀硬金最高（含金盐成本）。
- **电测与测试架**：飞针适合小批量，测试架（专用夹具）有一次性费用。
- **品质与文件**：切片、阻抗、可靠性抽检与出货报告。
- **管理与合理利润**：通常 10-25%，加急、小批量、特殊工艺会更高。

结论：只比较单价无法判断贵贱，必须把 NRE、测试架费、运费、付款条件一起算"总拥有成本（TCO）"。

## 六、批量阶梯与计价方式

| 阶段 | 典型数量 | 计价特点 | 单价水平 |
|------|---------|---------|---------|
| 打样 | 5-10 片 | 按款收 NRE + 板费 | 最高（单片可能是量产的数倍） |
| 小批量 | 50-500 片 | NRE 摊薄，按平米/片计价 | 明显下降 |
| 中批量 | 500-5000 片 | 可谈阶梯价、免 NRE | 接近量产价 |
| 大批量 | 5000 片以上 | 按平米阶梯价、年降机制 | 最低，交期最长 |

- **计价单位**：小批量常按"片/款"报价，量产普遍按"平方米（或平方英尺）"计价。
- **阶梯报价**：同一款板按 100/500/1000/5000 片给出不同单价，采购应索取阶梯价而非单点报价。
- **拼版利用率**：合理拼版能显著降低分摊到单片上的材料成本，是低层数板降本的第一手段。
- **长单与年降**：稳定量产需求可谈年度框架协议与年降条款，但需约定铜价波动时的调价机制。

## 七、常见加价项清单

- **加急（Quick Turn）**：加急通常上浮 30%-100%，24 小时特急更高。
- **阻抗控制**：需要 TDR 测试与叠层管控，通常加价。
- **盲埋孔 / HDI 积层**：每增加一次积层，报价显著上升。
- **特殊表面处理**：电镀硬金（金厚 1μm 以上）按金价与面积加价。
- **厚铜**：2oz 以上铜厚加价，层数与铜厚叠加更贵。
- **高频 / 高速材料**：材料本身贵，且需混压与专用工艺。
- **小尺寸 / 异形板**：影响拼版利用率，抬高单价。
- **测试架费**：量产首单的一次性夹具费用。
- **特殊包装 / 出货文件**：真空包装、COC、第三方检测（SGS 等）。
- **样品快递与关税**：跨境样品运费与目的国关税。

## 八、供应商审核（审厂）清单

- **资质**：ISO9001、IATF16949（车规）、ISO13485（医疗）、UL、RoHS / REACH。
- **设备**：钻孔（机械/激光）、层压、图形、表面处理线、AOI、飞针/测试架、TDR、切片实验室。
- **产能与交期**：月产能（平米/月）、设备稼动率、常规交期与加急能力。
- **工程能力**：CAM / MI 团队规模、DFM 反馈时效、阻抗与叠层仿真能力。
- **品质体系**：来料检验、过程 SPC、出货报告、客诉处理与 8D 闭环。
- **财务与稳定性**：成立年限、客户结构、是否存在过度依赖单一客户。
- **合规**：环保批文、危废处理、劳工与安全记录。

## 九、商务条款与风险控制

- **付款方式**：打样多要求预付或款到发货；量产常见 30% 定金 + 70% 见提单副本，或月结 30-60 天。
- **价格有效期**：覆铜板与铜价波动大，报价通常约定 15-30 天有效期。
- **交期与违约**：明确交期起算点（收到资料 / 确认 EQ / 收到定金），约定延误赔付。
- **品质责任**：明确不良判退标准、返工/重做/赔付比例与责任边界（来料 / 设计 / 制程）。
- **模具与治具**：测试架、模具的归属与保管责任应写入合同。
- **保密与知识产权**：签署 NDA，约定 Gerber 文件与设计资料的保密义务。
- **不可抗力**：缺料、限电、环保检查等情形下的交期顺延约定。

## 十、跨境/外贸采购特别注意

- **认证与合规**：出口欧盟需 RoHS / REACH，出口美国关注关税与原产地规则。
- **沟通时差与语言**：明确工程问答（EQ）的回复时效与对接人，避免"等回复"拖交期。
- **物流**：样品多走国际快递（DHL / FedEx / UPS），批量走空运/海运；需确认运费与关税由谁承担（FOB / CIF / DDP）。
- **付款风险**：新客户建议使用 T/T 预付或信用证（L/C），降低汇率与信用风险。
- **文件**：商业发票、装箱单、原产地证（COO）、材质证明（RoHS 报告）需齐套。
- **售后**：跨境退换货成本高，应在合同阶段明确赔付折算方式，避免实物退回。

## 十一、采购流程 SOP（从询价到量产）

1. **需求确认**：确定层数、板材、尺寸、表面处理、阻抗要求、数量与交期，整理成 RFQ 文档。
2. **询价与比价**：向 3 家以上同能力板厂询价，索取包含 NRE、测试架费与运费的总价，并确认报价有效期。
3. **DFM 评审**：提交 Gerber 做可制造性分析，确认线宽/孔径/间距是否在板厂能力范围内，提前修改设计缺陷。
4. **打样验证**：小批打样并做外观、电测、切片、阻抗验证；车规/医疗需额外可靠性测试。
5. **小批量试产**：验证工艺一致性与良率稳定性，确认交期准时率。
6. **量产与审厂**：正式审厂，签质量协议与框架协议，约定验收标准、赔付与调价机制。
7. **来料验收与复盘**：按 AQL 抽检，记录不良率，定期复盘供应商绩效（交期、品质、响应）。
