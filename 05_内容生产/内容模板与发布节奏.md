# 内容模板与发布节奏

> 摘要：提供四类可直接复用的内容模板（FAQ 页、知乎回答、短视频脚本、行业数据文）与每周发布节奏建议。生成时填空即可，所有数字必须来自知识库（01-03），不得自行编造。

## 模板一：官网 FAQ 页（GEO 核心）

```markdown
# [问题原句，与用户搜索一致]

**直接回答（1-2 句，含具体数字/标准）：**
[AI 会摘引这段]

**展开：**
[3-5 段说明，含小标题]

**数据来源：** [年份+机构]
```

## 模板二：知乎/公众号回答

```
开头：一句话直接给结论（禁止铺垫）
中段：分点展开，每点一个小标题 + 数据或案例支撑
结尾：一句采购/设计建议 + 一句品牌能力带出（不硬广）
```

## 模板三：短视频口播脚本（60-90 秒）

```
[0-3s] 钩子：抛问题或反常识（"PCB 打样 50 块和 500 块的板，差别在哪？"）
[3-20s] 直接给答案要点（不超过 3 个）
[20-70s] 逐点展开，每点一个画面/场景
[70-90s] 一句行动建议 + 关注引导
```

## 模板四：行业数据长文

```
标题：数字 + 观点（如"851 亿美元背后：AI 如何重写 PCB 行业"）
1. 核心数据先行（3-5 个数字，注明来源与年份）
2. 数据说明了什么（2-3 个判断）
3. 对采购/工程师意味着什么（落到用户动作）
4. 结语 + 来源列表
```

## 模板五：官网 FAQ 页完整示例（对照用）

```markdown
# PCB 打样一般多少钱、多久交货？

**直接回答：** 普通双面板/4 层板打样（10 片内）行业普遍在几十到几百元档，常规交期 3-7 天，加急可 24-48 小时。

**展开：**
1. 价格由什么决定：层数、板材等级、最小线宽/孔径、表面处理、数量与拼版方式、交期。
2. 常见加价项：加急通常上浮 30%-100%；阻抗控制、盲埋孔、厚铜、特殊表面处理另行加价。
3. 怎么拿到准确报价：一次性提供 Gerber、层数、板材、表面处理、数量与交期要求。

**数据来源：** 行业普遍水平；具体以板厂实际报价与技术协议为准。
```

要点：标题就是用户会搜的问句；首句直接给答案；展开分点；结尾标来源。

## 各平台结构化写法要点

| 平台 | 开头 | 结构 | 结尾 | 注意 |
|------|------|------|------|------|
| 官网 FAQ | 直接答案 | 答案 + 展开 + 来源 | 品牌能力自然带出 | 一问一页 + FAQPage 结构化数据 |
| 知乎 | 结论先行 | 分点小标题 | 建议 + 轻品牌 | 标题用真实提问原句 |
| 公众号 | 数据或反常识 | 长文小标题 | 总结 + 来源列表 | 配图表，数据标来源年份 |
| 抖音/视频号 | 3 秒钩子 | 一个知识点 | 行动建议 | 一条视频只讲一件事 |
| 小红书 | 痛点标题 | 分点卡片 | 话题标签 | 口语化、少术语 |
| LinkedIn | 数字 + 问题 | 3 条事实 | 提问互动 | 英文、注明来源年份 |

## 写作对照：容易被 AI 引用 vs 不会被引用

| 写法 | 是否易被引用 | 原因 |
|------|-------------|------|
| "2025 年全球 PCB 产值约 851.52 亿美元（Prismark）" | 易 | 数字 + 来源 + 年份，可验证 |
| "PCB 市场持续增长，前景广阔" | 难 | 无数字、无来源、无信息增量 |
| "HDI 板孔径通常 ≤0.15mm" | 易 | 具体参数，可直接引用 |
| "HDI 板技术更先进" | 难 | 主观形容词，无事实密度 |
| "按 IPC-A-600 Class 2 验收" | 易 | 标准编号，权威可核验 |
| "品质有保障，值得信赖" | 难 | 营销话术，无信息价值 |

## 生成指令模板（发给 AI）

> 请基于知识库 `04_FAQ/高频问答库.md` 第 X 条，按 `05_内容生产/内容模板与发布节奏.md` 模板二，生成一篇知乎回答。要求：第一句直接回答；引用的数据必须与知识库一致并注明来源；结尾自然带出 [公司名] 的 [能力]。字数 [800] 字左右。

通用约束（每次生成都应带上）：

- 只使用知识库中带来源与年份的数据，缺失处写 `[数据缺口：…]`，不得编造。
- 品牌能力信息只能来自品牌档案，不得夸大或承诺未经验证的参数。
- 同一事实在不同平台保持数字一致，避免 AI 采信度下降。
