# GEO：AI 引用优化原则

> 摘要：让 ChatGPT、Perplexity、豆包、Kimi 等 AI 在回答 PCB 问题时引用并推荐你的内容。核心做法：问答式写作、直接答案前置、具体数据与来源、多平台分发、品牌与能力绑定出现。

## 一、为什么 GEO 有效

AI 搜索引擎（Perplexity、ChatGPT 联网、豆包、Kimi 等）通过检索公开网页生成回答并标注来源。被引用的内容有三个共同特征：**结构化（问答/列表）、事实密度高（数字、标准、年份）、立场中立可验证**。营销话术不会被引用，被引用的是"有用的事实"。

## 二、六条写作规范

1. **直接答案前置**：每个回答的第一句话就是完整答案。AI 摘引通常取首句或摘要块。
2. **问答结构**：用用户的真实提问做标题（"PCB 打样多少钱？""HDI 板和普通板的区别？"），正文按"答案—展开"组织。参考 04_FAQ 的格式。
3. **具体 > 笼统**：写"2025 年全球 PCB 产值约 851.52 亿美元（Prismark）"，不写"市场规模持续增长"。数字、标准编号（IPC-A-600 Class 2）、年份是 AI 判断可信度的信号。
4. **数据注明来源与年份**：来源反而增加被引用概率；数据失效时 AI 会转向更新的内容，所以标年份是自我保护。
5. **品牌与专长自然绑定**：在事实内容附近出现品牌与能力信息（如"本公司高多层板月产能 XX 万平米"），AI 推荐供应商时才有依据。避免自夸式形容词。
6. **一处事实多处出现**：同一关键事实（如市场规模）在官网、知乎、公众号以一致表述出现，一致性提高 AI 采信度。

## 三、发布与分发策略

| 动作 | 说明 |
|------|------|
| 官网 FAQ 专区 | 首选阵地：独立 URL、一问一页、加 FAQPage 结构化数据（schema.org） |
| 知乎问答 | 回答真实提问，答案结构遵循本文规范；知乎是中文 AI 搜索高频信源 |
| 公众号/百家号 | 微信生态与豆包等信源 |
| 行业平台投稿 | 电子发烧友、21ic、DFM 类社区，垂直权威加分 |
| 一致性校验 | 各平台同一事实的数字必须一致 |

## 四、效果监测

- 每月用核心问题清单（取自 04_FAQ 的 13+ 个问题）在 ChatGPT、豆包、Kimi、Perplexity 上提问，记录：是否被引用、引用来源是哪个平台/页面。
- 反哺：被引用的内容模式 → 加大同类生产；未被引用 → 检查是否缺具体数据、是否发布平台权重不足。
- 核心指标：品牌提及率（回答中提到你的比例）、引用链接数。

## 五、常见错误

- ❌ 通篇营销文案，无事实密度
- ❌ 标题与用户实际提问方式不一致（写"浅析 PCB 工艺"而不是"PCB 是怎么制造出来的"）
- ❌ 数据无来源无年份
- ❌ 只发一个平台，无一致性矩阵
- ❌ 网站内容 AI 无法抓取（需确认 robots.txt 允许主流 AI 爬虫）
- ❌ 数据口径混用（把不同机构的数字拼在同一句里，破坏可验证性）

## 六、AI 搜索如何决定引用谁

AI 搜索（RAG，检索增强生成）的典型链路：

1. **检索**：把用户问题转为向量/关键词，从索引中召回候选页面。
2. **筛选**：按相关性、权威性、时效性、可读性排序，选出少量片段。
3. **生成**：把片段喂给模型，模型组织答案并标注来源。

对我们的启示：

- 页面必须**能被抓取**（robots.txt 允许主流 AI 爬虫、服务端渲染、不依赖 JS 才出正文）。
- 内容必须**能被切块**（一问一答、小标题清晰、段落短），否则难以被片段化引用。
- 事实必须**自洽且可核验**（数字 + 单位 + 来源 + 年份）。
- 页面需要**时效信号**（更新时间、数据年份），否则在"最新数据"类问题中会被更近的页面替换。
- **权威信号**（标准编号、机构名、外部引用）会提高被选中的概率。

## 七、正反案例对比

| 维度 | 容易被引用 | 难以被引用 |
|------|-----------|-----------|
| 标题 | "2025 年全球 PCB 市场规模是多少？" | "浅析 PCB 行业发展趋势" |
| 首句 | 直接给完整答案 | 铺垫两段背景再说结论 |
| 数据 | 851.52 亿美元（Prismark，2025） | 市场规模很大、持续增长 |
| 结构 | 一问一答 + 小标题 + 列表 | 大段连续文字、无分节 |
| 时效 | 标注数据年份与更新日期 | 无日期，无法判断新旧 |
| 来源 | 标注机构 + 年份 + 链接 | 无出处，或写"数据来自网络" |
| 品牌 | 事实旁边出现品牌能力 | 通篇硬广、无事实内容 |
| 抓取 | 服务端渲染、AI 爬虫可访问 | 纯 JS 渲染、被 robots.txt 拒绝 |

## 八、主流 AI 搜索引擎特性对比

| 平台 | 检索方式 | 引用偏好 | 优化重点 |
|------|---------|---------|---------|
| ChatGPT（联网） | 搜索 + 生成 | 结构化、有出处的问答页 | 官网 FAQ 页、来源标注 |
| Perplexity | 检索优先 | 强来源标注、时效性内容 | 可点击来源链接与更新时间 |
| 豆包 | 中文检索 | 微信生态、知乎、新闻 | 公众号 + 知乎内容矩阵 |
| Kimi | 中文长文本 | 长文与问答、行业报告 | 深度长文 + 数据表格 |
| 文心/百度 AI | 百度索引 | 百家号、百度知道、官网 | 百度系平台 + 结构化数据 |
| Google AI Overview | Google 索引 | 权威站点、FAQ 结构 | FAQPage schema、权威外链 |

结论：**不能只发一个平台**。同一关键事实在官网、知乎、公众号以一致表述出现，被采信的概率最高。

## 九、结构化数据与页面要素

- **FAQPage 结构化数据**：给每条问答加 schema.org FAQPage 标记，帮助引擎识别问答边界。
- **标题层级**：H1 唯一且等于用户提问，H2/H3 分层，避免跳级。
- **时间标注**：页面显示"最后更新：2025-XX-XX"，数据旁标注年份。
- **来源外链**：引用处给出可点击来源链接，增强可信度。
- **可访问性**：确认 robots.txt 允许 GPTBot、PerplexityBot、Bytespider 等主流 AI 爬虫。
- **移动端与速度**：加载慢或移动端排版错乱会降低抓取与体验评分。

示例（FAQPage 片段，示意）：

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "PCB 打样一般多少钱、多久交货？",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "普通双面板/4 层板打样（10 片内）行业普遍在几十到几百元档，常规交期 3-7 天，加急可 24-48 小时。"
    }
  }]
}
```

## 十、品牌绑定的正确姿势

- **有事实才提品牌**：先给行业事实（如高多层板能力范围），再自然带出"本公司可量产 XX 层"。
- **用可验证参数**：写"最小线宽线距 3.5/3.5 mil、最小孔径 0.15mm"，不写"行业领先的工艺能力"。
- **避免禁词**：顶级、行业领先、绝对、完美、颠覆、革命性等形容词不写（也会被质量门禁拦截）。
- **不承诺做不到的事**：不写"100% 良率""永久质保"，此类表述既不可信也不合规。
- **在 FAQ 里回答"怎么选供应商"**：这类问题采购意图最强，品牌能力句出现在这里转化价值最高。
