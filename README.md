# PCB 行业知识库

面向 **AI 被动内容生产**（GEO/AI搜索引用 + AI 内容生成素材）的行业知识库。

## 目录结构

```
pcb_knowledge_base/
├── README.md                  ← 本文件
├── 00_使用指南.md              ← 如何喂给AI、如何维护
├── 01_行业基础/
│   ├── PCB类型与板材.md        ← 板材分类、高频高速材料、选材逻辑
│   └── 制造工艺流程.md         ← 从开料到成品的全流程、HDI/刚挠结合难点
├── 02_行业格局/
│   └── 市场数据与趋势.md       ← 2024-2026市场数据、AI驱动、含数据来源
├── 03_选型与采购/
│   ├── 采购决策指南.md         ← 厂商评估五维法、报价逻辑、避坑
│   └── 质量标准与验收.md       ← IPC标准体系、验收要点、行业认证
├── 04_FAQ/
│   └── 高频问答库.md           ← AI搜索最常引用的问答格式（GEO核心资产）
├── 05_内容生产/
│   ├── 选题角度库.md           ← 可直接批量生成内容的选题池
│   └── 内容模板与发布节奏.md   ← 各平台模板、结构化写法
└── 06_GEO优化/
    └── AI引用优化原则.md       ← 让ChatGPT/豆包/Perplexity引用你的写法规范
```

## 两条使用路径

1. **被动引用（GEO）**：把 `01-04` 目录的内容发布到官网/知乎/公众号等公开渠道，按 `06_GEO优化` 的规范写作，让 AI 搜索引擎在回答用户问题时引用并推荐你。
2. **主动生产**：用 `05_内容生产` 的选题库和模板，让 AI 基于本知识库批量生成社媒、文章、短视频脚本。
